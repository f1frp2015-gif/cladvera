# Cladvera Fold V4

Approved orange/black identity, 23 October 2026. The horizontal SVG masters contain outlined lettering and proportional clearspace. Keep their aspect ratio; do not recreate the lettering with a web font or move the two planes independently.

- Symbol height / width: phi = 1.61803398875.
- Edge angle: atan(phi^-2) = 20.905157 degrees.
- Minimum opening: symbol height / phi^5.
- Horizontal wordmark ink height: symbol height / phi.
- Gap and minimum clearspace: symbol height / phi^3.
- Colors: architectural ink #292D2B, terracotta orange #C9633E, warm paper #F3F0E8.

`public/images/brand/` contains the original horizontal masters and the square identity image used by Organization structured data. `app/icon.svg` preserves the two-plane geometry on a warm paper square; `app/apple-icon.png` is its 180 px raster counterpart. The Open Graph image uses the same horizontal master. Header and footer home links supply accessible labels, so their decorative logo images use empty alternative text.

Source design: `design/cladvera-fold-golden-v4-2026-10-23` in the parent workspace. Font software is not distributed; the logo assets require no external fonts.
