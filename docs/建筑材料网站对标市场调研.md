# 建筑材料网站对标市场调研

> **整合声明 · v1.0**：本文件整合六个品牌的官网观察与 Cladvera 的实施判断。后续更新同一文件及 changelog，不建立日期版本副本。

> **目的**：帮助 Cladvera 将品牌展示、设计方向、材料比较、技术资料与项目询价连接起来。受众为网站设计、内容和销售团队；本次研究用于网站实施，不是品牌排名、流量研究或材料性能评测。

## 1. 研究范围与证据

2026-10-09 读取品牌官方产品、资料和应用页面。EQUITONE 首页另进行了浏览器视觉观察：大幅建筑照片、简明产品说明和样品入口形成首屏；多层导航分别组织材料、系统、资料与灵感。其余结论主要来自官方网页内容和导航结构，不推断未验证的交互效果或转化率。

项目工作区与可访问的 Documents 文件中未检出同主题研究，故在本仓库 docs 下建立维护文档。保留当前 Cladvera 的品牌语言，以功能和信息结构为重点，不复制同行页面、标识或项目作品。

## 2. 官网模式与适用判断

| 品牌与官方依据 | 观察到的做法 | Cladvera 的实施判断 |
| --- | --- | --- |
| [EQUITONE 首页](https://www.equitone.com/en-us/)；[linea 产品页](https://www.equitone.com/en-us/materials-en-us/linea/) | 导航区分材料、系统、资料与灵感；产品描述讨论触感、视觉与光影，再进入技术信息。 | 首页增加设计意图入口；材料表达与规格核对保持相邻，但区分感受与性能。 |

以上是信息组织和视觉方法的借鉴，不构成对这些品牌材料性能、售后承诺或商业结果的独立验证。

## 3. 本轮落地

### 3.1 首页：从设计意图进入材料

四个编辑性方向为 Mineral & tactile、Precise & planar、Warm & layered、Sculptural & custom。每个方向包含材料参考、一个设计问题、现有候选产品和需要确认的事项。切换支持键盘；候选比较链接使用共享清单，避免直接覆盖访客已保存的材料。

方向是开始选材的提示，不是产品等级、真实色号或性能等价结论。外用 HPL 与室内板、GFRP 与定制 UHPC 仍作为不同构造和不同用途分别核对。

### 3.2 产品：可查阅的材料档案

TAKTL、ALMINE 产品模板连接概览、事实、设计和资料区。保留可验证的厂家信息、原图来源和适用性限定；ALMINE 图形仍明确标作示意图。TAKTL 系列页把面板系列、表面选择及配套连接件组织为可定位的索引。

内容核查发现当前 TAKTL Facade Elements 页面中表格与正文的尺寸表述存在差异。原本的“最大标准尺寸”断言改为按实际构造和当前厂家资料确认，避免扩大使用有歧义的数字。

### 3.3 资料：直接文件与申请路径

资料中心默认覆盖现有全部产品系列，支持关键词、材料、应用和文件状态的组合筛选。直接链接的原文件、厂家产品介绍页和项目资料申请是不同入口；不将产品介绍当作技术 PDF，也不暗示未获得的 CAD/BIM 已可下载。

### 3.4 应用：场景到资料

五个原有应用区保留：外立面、室内、交通与隧道、医疗和定制形态。图文排版突出各场景需要回答的设计问题，保留完整候选产品，并提供对应的产品筛选与资料筛选入口。

## 4. 内容和 SEO 边界

- 使用已有厂家或供应商图片；现阶段没有新增 Cladvera 已交付案例。
- 免费样品、本地库存、特定认证、碳足迹和保修等同行承诺不迁移到 Cladvera。
- 不新增未审核材料、品牌合作关系、颜色型号和技术下载。
- 沿用已审核的规范 URL、产品实体和索引范围。筛选页面是使用工具，不作为新的关键词落地页。
- 内链表达具体材料、应用与资料目的，避免所有页面重复竞争同一个泛词。
- 本次研究不提供关键词搜索量、排名提升或转化增长预测。
